# AIC of a `bgw_mle` object

Calculate the AIC of the model.

## Usage

``` r
# S3 method for class 'bgw_mle'
AIC(object, ..., k = 2)
```

## Arguments

- object:

  An object of class `bgw_mle`

- ...:

  Additional arguments

- k:

  The penalty parameter used. The default value is k = 2 for the
  classical AIC

## Value

A single double
