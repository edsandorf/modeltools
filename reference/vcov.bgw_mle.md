# Variance-covariance matrix of a `bgw_mle` object

Variance-covariance matrix of a `bgw_mle` object

## Usage

``` r
# S3 method for class 'bgw_mle'
vcov(object, ...)
```

## Arguments

- object:

  An object of class `bgw_mle`

- ...:

  Additional arguments

## Value

A numeric matrix with the variances and covariances of the estimated
parameters
